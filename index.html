Building 3D Engines From Scratch & Publishing on Xbox 360

Writing my first line of code at 15 sparked a lifelong fascination with understanding how computers work from the metal up. In university, that curiosity turned into authoring custom 3D game engines from scratch in C#—handling matrix math, collision physics, and rendering pipelines without relying on prebuilt engines.

As a solo engineer, I designed, developed, and commercially published two titles on the Xbox 360 Indie Games platform, learning early the grit, architectural discipline, and accountability required to take an idea from zero to a live commercial store.

Bringing Low-Level Systems Discipline to Modern Web Architecture

Transitioning to web engineering wasn't a departure from systems thinking—it was applying it to a different runtime. The instincts honed while managing frame budgets and CPU caches in games became direct superpowers on the web: keeping render trees shallow, preventing unnecessary re-renders, and treating network latency as a critical UX constraint.

Rather than treating the web as a loose assembly of scripts, I approach it with the same structural rigor as systems software: clear boundaries across layers, deterministic state flow, and zero tolerance for sluggish user interfaces.

TypeScript End-to-End, React 19 Ecosystem & Resilient Node Services

My current day-to-day focus is modern full-stack TypeScript. On the frontend, I build with React 19, Next.js App Router, and modular design token systems that enforce visual consistency and strict design systems without bloat.

On the backend, I design clean Node.js and Express REST services backed by relational or document databases (PostgreSQL, MongoDB). Every project is backed by strict type safety, predictable testing, and high developer ergonomics that keep velocity fast.

Code Written for Humans First, Zero Layout Shift & Absolute Follow-Through

Great engineering isn't just about clever algorithms—it's about reliability, maintainability, and clarity. I hold myself to strict production standards: sub-second first loads, 0 Cumulative Layout Shift, WCAG AA accessibility, and clean architecture that any teammate can read, understand, and build upon without fear.

Whether owning a feature solo or collaborating across a team, dependable follow-through and empathetic communication are table stakes. I build solutions meant to be read, maintained, and scaled with confidence.
